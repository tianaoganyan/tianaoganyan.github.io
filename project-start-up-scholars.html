OVERVIEW

Start Up Scholars Academy is my tutoring and afterschool business, offering private tutoring, afterschool care, and programming and STEM classes. I wanted the site to feel warm and trustworthy for parents while still feeling playful for kids, so I paired a soft cream and green palette with friendly icons and a "Learn STEM with fun!" illustration. The site is a multi page build that explains each program clearly and makes it easy for families to call, text, or email to enroll.
